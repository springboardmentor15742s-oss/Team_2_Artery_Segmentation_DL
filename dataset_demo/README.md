# Included demo dataset

This folder contains 8 **synthetic, computer-generated angiography-style illustrations** for smoke testing upload, UI, and dataset loading. They are not patient images, not real X-rays, and are not suitable for clinical training or performance claims. Labels and percentages are illustrative only. No real patient details are present.

For research training, obtain a licensed dataset (e.g. ARCADE) and inspect its own label definitions/annotation format before training.
